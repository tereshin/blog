# SVG icons

Каталог `fill/` и `line/`, компонент `src/shared/ui/BaseIcon.tsx` и генератор перенесены из предоставленного пользователем `mashu-ai-chat/project-app`.

Использование: `<BaseIcon name="happy" style="line" size={20} />`, импорт из `@/shared/ui`. Иконки декоративны по умолчанию; `alt` задаёт доступное имя самостоятельной иконки. Размер и цвет можно переопределять CSS-классами.

После добавления иконки выполните `pnpm --filter web icons`. Генератор проверяет имена и создаёт `src/shared/ui/icons.generated.ts` только из используемых SVG. Исходный каталог не публикуется и не импортируется браузером. Сборка проверяет актуальность через `icons:check`.
