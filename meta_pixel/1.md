На вашем скриншоте для отслеживания конверсий подходит первый пункт — «Создать специально настроенную конверсию».

Но сначала нужно убедиться, что Meta Pixel установлен на сайте и получает события. Иначе созданная конверсия не будет собирать данные.

## Порядок настройки

1 Проверить Meta Pixel

Откройте Events Manager → Источники данных → ваш Pixel → Тестирование событий.

Перейдите на сайт и проверьте, появляется ли событие `PageView`. Это подтвердит, что пиксель отправляет данные.

2 Определить целевое действие

Например:

- `Lead` — отправка заявки
- `CompleteRegistration` — регистрация
- `Purchase` — покупка
- `Contact` — обращение клиента

Для действий без отдельной страницы подтверждения обычно настраивается отправка события при успешном выполнении действия.

3 Создать конверсию

Выберите первый пункт на скриншоте, затем источник данных и правило.

Например, если после отправки формы пользователь попадает на `/thank-you`, можно создать конверсию по условию `URL содержит /thank-you`.

4 Проверить и использовать в рекламе

Выполните тестовую конверсию, убедитесь, что она регистрируется, и выберите нужное событие или специально настроенную конверсию при настройке группы объявлений Meta Ads.

Такой подход соответствует процессу настройки Meta Pixel и событий, описанному в [официальном обучении Meta](https://www.facebookblueprint.com/student/activity/248027?utm_source=chatgpt.com).

Для отслеживания отправки формы в Meta Pixel рекомендую использовать стандартное событие `Lead`. Оно должно срабатывать только после успешной отправки заявки, а не при нажатии кнопки «Отправить».

Поскольку Meta Pixel уже установлен и получает данные, повторно устанавливать его не нужно.

## Шаг 1. Проверить, есть ли событие Lead

1. Откройте [Meta Events Manager](https://business.facebook.com/events_manager2/?utm_source=chatgpt.com).
2. Перейдите в раздел «Источники данных».
3. Выберите ваш Pixel.
4. Откройте вкладку «Тестирование событий».
5. Откройте сайт и отправьте тестовую заявку.
6. Посмотрите, появилось ли событие `Lead`.

Возможны два результата:

- `Lead` появился — отслеживание отправки заявки уже работает. Переходите к шагу 4.
- Отображается только `PageView` — пиксель видит посещения сайта, но отправка формы ещё не отслеживается. Нужно настроить событие.



## Шаг 2. Выбрать способ отслеживания формы

Здесь всё зависит от поведения сайта после успешной отправки.

Вариант А — перенаправление на страницу благодарности

Например, после отправки пользователь попадает на `site.com/thank-you`.

Тогда можно использовать первый пункт с вашего скриншота — «Создать специально настроенную конверсию», не меняя код сайта.

Вариант Б — форма отправляется без перезагрузки страницы

Например, пользователь нажимает «Отправить», и появляется сообщение «Спасибо, заявка отправлена».

Здесь надёжнее отправлять событие `Lead` непосредственно после успешного ответа сервера.

## Шаг 3. Настроить событие



### Вариант А — через интерфейс Meta

Если у вас есть отдельная страница `/thank-you`:

1. В Events Manager откройте «Специально настроенные конверсии».
2. Нажмите «Создать» → «Создать специально настроенную конверсию».
3. Выберите ваш Pixel в качестве источника.
4. Укажите событие `PageView` или «Весь трафик URL», если такое значение доступно.
5. Создайте правило: URL → содержит → `/thank-you`.
6. Назовите конверсию `Lead - Website Form`.
7. Если доступен выбор категории, укажите «Лид».
8. Нажмите «Создать».

Это позволит учитывать посещения страницы благодарности как конверсии. Убедитесь, что туда можно попасть только после успешной заявки.

### Вариант Б — через JavaScript

Если форма отправляется асинхронно, добавьте вызов в обработчик успешной отправки:

```

async function submitLead(formData) {
  const response = await fetch('/api/leads', {
    method: 'POST',
    body: JSON.stringify(formData),
    headers: {
      'Content-Type': 'application/json'
    }
  });

  if (!response.ok) {
    throw new Error('Failed to submit lead');
  }

  // Срабатывает только после успешной отправки
  if (typeof window.fbq === 'function') {
    window.fbq('track', 'Lead');
  }
}

```

Это пример для сайта, где API возвращает успешный HTTP-статус только после фактического принятия заявки. Вызов нужно встроить в существующий обработчик, а не подключать как отдельную повторную отправку формы.

Важно: не отправляйте `Lead` одновременно из нескольких механизмов без настройки дедупликации, иначе количество заявок может завышаться.

## Шаг 4. Проверить конверсию и подключить к рекламе

После настройки:

1. Вернитесь в «Тестирование событий».
2. Отправьте новую тестовую заявку.
3. Проверьте появление `Lead` (для варианта Б) либо `PageView` страницы благодарности и активность специальной конверсии (для варианта А).
4. Откройте Meta Ads Manager и создайте кампанию с целью «Лиды».
5. На уровне группы объявлений выберите сайт как место получения конверсий, ваш Pixel и событие `Lead` либо созданную специальную конверсию.
