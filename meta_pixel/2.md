Для вашего сайта я рекомендую настроить Google Tag Manager (GTM) как единый центр управления аналитикой, а Google Analytics 4 (GA4) — для анализа посетителей, источников трафика и заявок.

У вас уже работает Meta Pixel и настроено событие `Lead` при успешной отправке AJAX-формы. Мы сохраним эту настройку и добавим параллельное отслеживание заявок в GA4.

## 1. Как будет работать аналитика

Ваш сайт

Посещения, клики, успешные заявки

Google Tag Manager

Получает события и запускает теги

GA4

Аналитика и конверсии

Meta Ads

Оптимизация рекламы по Lead

Целевая схема. Meta Pixel можно оставить установленным напрямую или позднее перенести в GTM.

После настройки вы сможете узнавать, сколько пользователей приходит из Facebook, Instagram и Google, какие страницы они посещают и какие источники приносят реальные заявки.

## 2. Создайте Google Analytics 4

ШАГ 1

1. Перейдите на [Google Analytics](https://analytics.google.com/?utm_source=chatgpt.com).
2. Нажмите «Начать измерение», если ещё нет аккаунта.
3. Создайте аккаунт и ресурс GA4, выберите часовой пояс и валюту.
4. Добавьте поток данных с типом Web (Сайт).
5. Укажите домен сайта.
6. Скопируйте Measurement ID.

Он выглядит следующим образом:

MEASUREMENT ID — ПРИМЕР

&#x20;Копировать

# G-XXXXXXXXXX

Вам понадобится этот ID для создания тега в GTM.

## 3. Создайте Google Tag Manager

ШАГ 2

1. Откройте [Google Tag Manager](https://tagmanager.google.com/?utm_source=chatgpt.com).
2. Нажмите «Создать аккаунт».
3. Введите название аккаунта и выберите страну.
4. Создайте контейнер с названием домена.
5. Выберите платформу Web.
6. Скопируйте код установки GTM.

Вы получите идентификатор формата `GTM-XXXXXXX` и два фрагмента кода.

Установите первый фрагмент максимально высоко внутри `<head>`, а второй — сразу после открывающего тега `<body>` согласно инструкции GTM. Для React/Next.js используйте интеграцию в корневом layout либо соответствующий механизм загрузки скриптов.

Если GA4 уже установлен напрямую, проверьте его перед подключением через GTM, чтобы не дублировать `page_view`.

## 4. Подключите GA4 через GTM

ШАГ 3

В Google Tag Manager выполните следующие действия:

1. Перейдите в «Теги» → «Создать».
2. Назовите тег `Google Tag - GA4`.
3. Выберите тип Google Tag (Тег Google).
4. В поле Tag ID вставьте ваш `G-XXXXXXXXXX`.
5. В качестве триггера выберите Initialization - All Pages.
6. Сохраните тег.

Это рекомендуемый Google способ подключения GA4 через GTM.&#x20;

## 5. Настройте отслеживание отправки формы через GTM

ШАГ 4 — САМАЯ ВАЖНАЯ ЧАСТЬ

Поскольку ваша форма отправляется без перехода на другую страницу, лучше всего использовать `dataLayer`.

`dataLayer` — это массив событий и данных, через который ваш сайт взаимодействует с GTM.

### 5.1. Добавьте событие в код сайта

В уже существующем обработчике успешной отправки, рядом с Meta Pixel `Lead`, добавьте:

```

window.dataLayer = window.dataLayer || [];

window.dataLayer.push({
  event: 'lead_form_success',
  form_name: 'contact_form'
});

```

Вызов должен выполняться только после успешного сохранения заявки.

В итоге ваш обработчик будет выглядеть примерно так:

```

async function handleSubmit(formData) {
  const response = await fetch('/api/leads', {
    method: 'POST',
    headers: {
      'Content-Type': 'application/json'
    },
    body: JSON.stringify(formData)
  });

  if (!response.ok) {
    throw new Error('Lead submission failed');
  }

  // Уже настроенный Meta Pixel
  if (typeof window.fbq === 'function') {
    window.fbq('track', 'Lead');
  }

  // Событие для Google Tag Manager
  window.dataLayer = window.dataLayer || [];
  window.dataLayer.push({
    event: 'lead_form_success',
    form_name: 'contact_form'
  });

  // Показываем сообщение об успехе
  showSuccessMessage();
}

```

Это пример архитектуры, а не код для прямой замены вашего обработчика. В реальном приложении важно также блокировать повторные отправки и не считать повторную обработку одной заявки новой конверсией.

### 5.2. Создайте триггер в GTM

В интерфейсе Google Tag Manager:

1. Перейдите в «Триггеры» → «Создать».
2. Название: `Lead - Form Success`.
3. Тип триггера: «Пользовательское событие» (Custom Event).
4. Имя события: `lead_form_success`.
5. Выберите «Все пользовательские события».
6. Сохраните.

### 5.3. Создайте тег отправки конверсии в GA4

Перейдите в «Теги» → «Создать».

Укажите:

| Поле             | Значение                      |
| ---------------- | ----------------------------- |
| Название         | GA4 - Generate Lead           |
| Тип тега         | Google Аналитика: событие GA4 |
| Measurement ID   | `G-XXXXXXXXXX`                |
| Название события | `generate_lead`               |
| Триггер          | Lead - Form Success           |

Используйте именно `generate_lead` — это стандартное рекомендованное Google событие для получения заявки.&#x20;

## 6. Проверьте, что данные поступают в GA4

ШАГ 5

1. В GTM нажмите Preview.
2. Подключитесь к сайту через Tag Assistant.
3. Отправьте тестовую заявку.
4. В левой части Tag Assistant найдите событие `lead_form_success`.
5. Убедитесь, что на нём сработал тег `GA4 - Generate Lead`.

Затем откройте Google Analytics → Администратор → DebugView или раздел «В реальном времени» и проверьте появление события `generate_lead`. Для DebugView может потребоваться включить режим отладки GA4.

## 7. Отметьте событие как ключевое в GA4

ШАГ 6

Событие уже будет поступать в GA4, но для анализа конверсий его нужно пометить как ключевое событие (Key event).

В Google Analytics:

1. Откройте Администратор → Отображение данных → Ключевые события.
2. Нажмите «Новое ключевое событие», если `generate_lead` ещё не отображается.
3. Введите точное имя `generate_lead`.
4. Сохраните.

Если событие уже присутствует в списке «События», можете отметить его как ключевое там.&#x20;

## 8. Опубликуйте контейнер GTM

Вернитесь в GTM, нажмите «Отправить» (Submit), затем «Опубликовать».

Рекомендую назвать версию `GA4 - Lead Conversion Tracking`, чтобы позднее было понятно, какие изменения внесены.

## 9. Настройте источники трафика через UTM

Чтобы GA4 мог точно различать ваши рекламные кампании, добавьте UTM-параметры в ссылки объявлений Meta.

Например:

```

https://example.com/contact?
utm_source=facebook&
utm_medium=paid_social&
utm_campaign=lead_generation

```

В одной реальной ссылке параметры должны быть без переносов строк.

GA4 будет использовать их для атрибуции посещений и заявок.

Дополнительно рекомендую настроить Google Consent Mode v2, если вы обрабатываете данные посетителей из ЕЭЗ: он передаёт Google выбранные пользователем разрешения на аналитику и рекламу.&#x20;

В итоге у вас будут две независимые системы измерения: Meta Pixel получает `Lead` для оптимизации рекламы в Facebook/Instagram, а GA4 получает `generate_lead` для анализа источников трафика и эффективности сайта. Количество конверсий в них может отличаться из-за атрибуции, согласий пользователей и блокировщиков.

При этом вам не нужно переносить уже работающий Meta Pixel в GTM. Его можно оставить как есть и использовать GTM только для GA4 и других будущих интеграций.
