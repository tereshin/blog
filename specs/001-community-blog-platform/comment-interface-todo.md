# Доработки обсуждения — выполнено

- [x] Закладки комментариев: сохранить/удалить, `is_bookmarked` в выдаче, список с курсорной пагинацией и вкладка «Комментарии» в закладках.
- [x] Жалобы: причина, защита от повторной жалобы одного участника, отдельная очередь модератора. Отклонение, скрытие и удаление; обработка жалобы и события модерации сохраняются одной транзакцией.
- [x] Участники, поставившие реакции: список по выбранному виду реакции, аватары, курсорная пагинация.
- [x] Серверная сортировка корней и ответов: `best`, `newest`, `oldest`. Курсор связан со статьёй/веткой и сортировкой; отдельные ключи кэша, обновление после мутаций.
- [x] Ответы загружаются при раскрытии ветки и листаются независимо от корней. `reply_count` передаётся отдельно от загруженных ответов.
- [x] Прямая ссылка загружает корень и целевой комментарий независимо от страницы, раскрывает ветку и прокручивает к ответу.
- [x] Изображения, GIF и упоминания: до четырёх файлов PNG/JPEG/WebP/GIF по 8 МБ через существующий media-service, предпросмотр/удаление до отправки. Сервер проверяет владельца и тип загруженного файла. Поиск участников и до десяти упоминаний; имена берутся из серверной копии профиля. Упомянутый участник получает уведомление со ссылкой на комментарий.
- [x] Подписка на обсуждение: включить/выключить, сохранение состояния, уведомления о новых комментариях/ответах через outbox. Один адресат получает одно уведомление, собственные действия исключены. Для закрытого автором обсуждения внешние адресаты исключены.

## API

Владелец всех перечисленных маршрутов — discussion-service, gateway маршрутизирует по существующему `/v1/comments` и `/v1/moderation/comments`.

| Метод              | Маршрут                                                                               | Назначение                                                                         |
| ------------------ | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| GET                | `/v1/articles/:article_id/comments?sort=best&include_replies=false&cursor=…&limit=20` | Корни обсуждения; `include_replies=true` сохраняет совместимость с прежней выдачей |
| GET                | `/v1/comments/:id/replies?sort=oldest&cursor=…&limit=20`                              | Страница ответов                                                                   |
| GET                | `/v1/comments/:id/thread`                                                             | Корень и целевой комментарий для прямой ссылки                                     |
| PUT / DELETE       | `/v1/comments/:id/bookmark`                                                           | Сохранить / убрать комментарий                                                     |
| GET                | `/v1/comments/bookmarks?cursor=…&limit=20`                                            | Закладки текущего участника                                                        |
| GET                | `/v1/comments/:id/reactors?kind=heart&cursor=…&limit=20`                              | Участники, поставившие выбранную реакцию                                           |
| POST               | `/v1/comments/:id/reports`                                                            | Жалоба с `{ reason }`                                                              |
| GET                | `/v1/moderation/comments/reports?cursor=…&limit=20`                                   | Открытые жалобы; только администратор                                              |
| PATCH              | `/v1/moderation/comments/reports/:id`                                                 | `{ action: "dismiss" / "hide" / "delete" }`                                        |
| GET / PUT / DELETE | `/v1/comments/subscriptions/:article_id`                                              | Состояние / подписка / отписка                                                     |
| GET                | `/v1/comments/mentions?q=…`                                                           | Поиск участников для упоминания                                                    |

`POST /v1/articles/:article_id/comments` принимает дополнительные поля `media: [{ url, alt }]` и `mentions: [{ user_id, display_name }]`. Правка текста сохраняет существующие вложения и упоминания. GIF добавляется загрузкой файла с устройства.

## Миграции

- discussion: `20261010_comment_interactions.sql` — вложения, упоминания, закладки, жалобы, подписки и индексы.
- notification: `20261010_comment_mentions.sql` — вид уведомления `mention`.

Дополнительные поля события `discussion.comment.created` (`mention_ids`, `subscriber_ids`) необязательны: прежние события продолжают обрабатываться.

## Проверки

Интеграционные тесты PostgreSQL покрывают доступ, сортировку, курсоры, ленивые ответы, прямые ссылки, закладки, повторные жалобы, модерацию, проверку файлов/упоминаний и outbox. Notification-тест проверяет дедупликацию адресатов и повторную доставку. Браузерные тесты покрывают меню, сортировку, отправку текста/изображения/GIF/упоминания, подписку, закладки, очередь жалоб, мобильный экран и доступность обсуждения.
