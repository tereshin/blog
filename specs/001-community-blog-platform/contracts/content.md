# Contract: Статья и файлы

Сохранение, публикация и документ блоков. Страница статьи открывается по `/p/{slug}` внутри каркаса ([article.md](./article.md)). Редактор — `/write` для новой и `/write/{id}` для существующей.

## Состояния, которые видит клиент

| Состояние | Кто видит текст | Где статья есть |
| --- | --- | --- |
| Черновик | Только автор | Редактор автора. Не лента, не поиск, не тема, не чужой профиль |
| Опубликована | Кто проходит видимость | Лента, тема, профиль, поиск, прямой адрес |
| Скрыта | Автор с пометкой, администратор в модерации | Не в ленте, поиске, теме, чужом профиле и правой карточке |
| Удалена | Никто | Адрес сообщает, что материал недоступен |
| Нет права читать | Никто из этого запроса | Ответ без текста и блоков: гостю при `members` — предложение войти, остальным — недоступность |

Сужение видимости у уже открытой страницы убирает текст без перезагрузки.

## Публикация и правка

Черновик становится опубликованным только при заголовке, одной активной теме и хотя бы одном содержательном блоке. Один разделитель публикацию не открывает.

Правка заголовка, блоков, темы, видимости и флага комментариев оставляет прежний `/p/{slug}`, пока автор сам не сохранил новый короткий адрес. Люди с открытой статьёй получают новый заголовок и текст. Люди с открытой лентой или темой получают новый заголовок и фрагмент.

Уход из редактора с несохранёнными правками спрашивает подтверждение и не стирает текст, если человек остаётся. Несохранённый комментарий под уже открытой статьёй правка автора не стирает.

Удаление автором переводит статью в `deleted`. Редактировать и удалить свою статью можно и из меню «…» карточки ([feed.md](./feed.md)).

## Подписка на автора и тему

Вошедший неограниченный участник подписывается на автора («Подписаться» на карточке и в чужом профиле) или на тему (на странице темы). Пара подписчик–цель одна, повтор снимает. На себя подписаться нельзя. Подписки кормят `GET /v1/feed?mode=mine` и числа на профиле.

## Продвижение

`POST /v1/articles/{id}/promotion` от автора статьи записывает `confirmed_at` и `until = confirmed_at + 7 суток`, заменяя прежние значения. Денег не списывается. Пока `until` в будущем, статья входит в `GET /v1/feed?mode=popular` независимо от даты публикации.

## Документ блоков

Корень — объект Editor.js: `time`, `blocks[]`, `version`. Каждый блок — `type` и `data`. Иной `type` отклоняется целиком, запись не проходит.

| type | data | Заметка |
| --- | --- | --- |
| paragraph | text | Встроенная разметка по списку ниже |
| header | text, level 2–4 | |
| list | style `unordered`, `ordered` или `checklist`; items, вложенность тем же списком | |
| quote | text, caption | |
| warning | title, message | Выноска |
| delimiter | пусто | Сам по себе статью не публикует |
| code | code | Текст кода как текст, не как HTML |
| image | file.url, caption | Адрес только что принятого файла площадки |
| embed | service, source, embed, width, height | `service` из списка известных. В страницу подставляется шаблон сервиса |
| table | content, withHeadings | Ячейки — текст с той же встроенной разметкой |
| attaches | file.url, title, size, extension | Адрес принятого вложения |
| personality | name, description, photo | Карточка человека |

Встроенный текст абзаца, заголовка, цитаты, списка, таблицы и выноски может содержать только `b`, `i`, `u`, `code`, `mark`, `br` и `a` с `href` на `http`, `https` или `mailto`. Код внутри строки — `code`. Выделение — `mark`. Ссылка — `a`. Всё остальное, включая обработчики и стиль, снимается до записи.

`image.file.url` и `attaches.file.url` указывают на файл, загруженный этой учёткой через приём файлов. Чужой или внешний адрес изображения в блок не записывается.

## Приём файла

`POST /v1/media` через `gateway` в `media-service`, от вошедшего участника с правом писать в редактор. Тело — поток, `X-Idempotency-Key` обязателен.

Ответ сервиса — `{ "id", "url", "kind", "mime", "byte_size" }`. Адаптер загрузчика Editor.js на клиенте переводит его в ожидаемую редактором форму `success: 1`, `file.url`. При отказе файл не сохраняется, прежний блок не меняется, человек видит причину (`application/problem+json`).

| kind | Типы | Потолок |
| --- | --- | --- |
| image | JPEG, PNG, WebP, GIF | 8 МБ |
| attachment | PDF, DOC, DOCX, TXT | 20 МБ |

Тип проверяется по содержимому. Имя файла на хранилище назначает сервер.
